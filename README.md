# ПРОЕКТНО ЗАДАНИЕ

## „Система за оценяване на студенти“

## 1. Обща информация

**Тип проект:** Проектно задание по производствена практика
**Ученик:** Аспарух Георгиев
**Клас:** XI Г клас
**Специалност:** Приложно програмиране
**Цел:** Разработване на уеб базирана система за управление и оценяване на студенти, която да улеснява преподавателите при въвеждане и анализ на оценки, както и да осигурява на студентите достъп до техните резултати, обратна връзка и учебни дейности.

## 2. Кратко описание на проекта

Проектът представлява разработка на уеб приложение, предназначено за въвеждане, съхранение и анализ на оценки по различни учебни дисциплини. Системата ще осигурява различни нива на достъп за учители и студенти, ще позволява създаване на тестове и домашни работи и ще предоставя автоматично изчисляване на резултати и генериране на отчети.

---

## 3. Функционални изисквания

- Регистрация и вход на потребители (учители и студенти) с различни нива на достъп.
- Управление на профили и лични данни.
- Въвеждане, редактиране и изтриване на оценки по дисциплини.
- Създаване на домашни работи и тестове.
- Автоматично оценяване на тестове.
- Преглед и анализ на успеха по дисциплини.
- Генериране на справки и отчети за резултатите.
- Достъп на студентите до собствените им оценки.

---

## 4. Технически изисквания

- Уеб базирано приложение, достъпно чрез интернет браузър.
- Използване на Java за бекенд разработка.
- Използване на база данни за съхранение на потребители, дисциплини и оценки.
- Реализация на RESTful API.
- Използване на HTML, CSS и JavaScript за потребителски интерфейс.
- Прилагане на трислойна архитектура.

### 4.1 Използвани технологии

- Java (Spring Boot)
- MySQL / PostgreSQL
- HTML, CSS, JavaScript
- Git и GitHub
- Postman (за тестване на API)

### 4.2 Архитектура

Системата ще бъде изградена по трислойна архитектура:

- **Presentation Layer** – потребителски интерфейс
- **Business Logic Layer** – обработка на логиката по оценяване
- **Data Access Layer** – комуникация с базата данни

### 4.3 API и сигурност

- Реализация на RESTful API за комуникация между клиент и сървър.
- Контрол на достъпа според потребителската роля.
- Криптиране на пароли.
- Защита на личните данни и информацията за оценките.

## 6. Тестване

Ще се извърши функционално и интеграционно тестване на всички модули – регистрация, въвеждане на оценки, създаване на тестове и генериране на отчети. Ще се провери правилното съхранение на данните, защитата на достъпа и коректността на автоматичното оценяване. След отстраняване на установени грешки ще се проведе повторно тестване.
